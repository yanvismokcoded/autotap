# tap-bot

Урезанная версия vz-бота — оставлена **только функция тапа**.

## Что есть
- Многопользовательский логин (каждый входит в свой Telegram-аккаунт)
- `/genkey`, `/activate` — регистрация по ключу от владельца
- `/login`, `/code`, `/password`, `/logout`, `/resend_code`, `/login_code`, `/api` — вход в аккаунт
- Автопересылка кодов входа из служебного чата Telegram (777000) в личку
- `/add_channel`, `/channels`, `/del_channel`, `/create_channel` — список каналов, которыми тапаем
- `/tap <ссылка> @юз [количество]` — сам тап (можно и без юза — возьмёт из поста/пересланного сообщения)
- `/del_tap` — забыть тап по посту
- `/settings`, `/set votes <число>`, `/status`

## Чего нет (в отличие от исходного vz-бота)
Убрано всё, что не относится к тапу напрямую:
- слежение за вз-чатами и автоматический поиск/предложение вз (`offers.js`)
- согласование "сообщите"/"тап после вас" и договоры о вз (канал договоров)
- автопост/рассылка по чатам, папки чатов
- техподдержка (`/support`)

Если что-то из этого понадобится обратно — вернуть несложно, файлы `userbot.js`, `tapper.js`, `parser.js` не менялись и совместимы с исходным проектом.

## Запуск
```
npm install
cp config.example.json /app/data/config.json   # или используйте переменные окружения
# отредактируйте apiId/apiHash/botToken (или задайте API_ID/API_HASH/BOT_TOKEN/OWNER_ID/CONFIG_DIR через env)
npm start
```

Первый, кто напишет боту `/start`, становится владельцем.
